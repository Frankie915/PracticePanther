# Practice Panther
The purpose of this project was to learn how to create a full-stack application in Visual Studio using C# and .NET.
This application is a remake of a of a website that allows lawyers to manage their clients and project/calculate 
profit based on time spent with client. MVVM strcuture was vital in creating the backend API and file base to the be 
connected to the View via the View Model. The project took sometime to complete with setbacks in the classroom, 
and CRUD functionality was then assigned to only the Clients of the database to demonstrate a fully functional 
part of the application.
